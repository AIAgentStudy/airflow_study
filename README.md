# Airflow 학습 패키지 (12주, 입문부터 실무까지)

이 폴더는 Apache Airflow 공식 문서(`https://airflow.apache.org/docs`)를 기준으로 만든 전체 학습 시스템입니다.

## 시작 순서

1. `00_시작하기.md` 읽기
2. `12주_커리큘럼.md` 따라가기
3. `상세_실행_가이드.md`의 일자별 학습 순서 실행
4. `문서/공식문서_학습맵.md`로 공식 문서 위치 확인
5. `주차별/` 파일로 매주 체크리스트 수행
6. `진행현황/진행추적표.md`에 진행 상황 기록
7. `templates/` 재사용
