# 완료 기준

## 주차 완료 조건

- [ ] 계획된 공식 문서를 읽었다.
- [ ] DAG를 최소 1개 직접 작성해 실행했다.
- [ ] 의도적 실패 시나리오를 최소 1개 수행했다.
- [ ] 실패 원인과 복구 과정을 기록했다.
- [ ] 진행표와 주간 노트를 업데이트했다.
- [ ] 노트 없이 핵심 개념을 설명할 수 있다.

## 모듈 완료 조건

- [ ] DAG 코드 구조가 명확하다.
- [ ] 비밀정보 하드코딩이 없다.
- [ ] 재시도/타임아웃이 명시되어 있다.
- [ ] 로그만으로 장애 지점 파악이 가능하다.
- [ ] 기본 자동화 테스트가 있다.
